## 来源与方法

来源是 Project Gutenberg #1184 的完整英文版，原作为法文，本次没有使用现代中文译本。原始 EPUB 的 SHA-256 为 `3f22a883c358df0435cfc6b40e69bf27229b36ce6a2285a9151183a0996973f8`。

第一章由当前 Codex 会话逐段新译。126 个正文段落各对应一段译文，1 项重复章标题、1 项插图说明、3 项插图链接编号单独保留为版面信息，不混入故事。原始文件和段落编号保持不变。译稿保留法国时代、音译姓名、航海细节、全部问答、合伙人的任命限制和章末街景。原文有关卸货及返航的时间表按原述翻译，其不一致处在译后记录中注明。

冻结首章译稿后，通过 MCP 建立独立重写项目，读取译稿与最初英文原作，提交逐字证据和结构解析，再锁定《长夜归舟》的民国框架。新正文围绕工资表、停航费用、仓单交接和未签任命重设行动因果，沿用林望舟、何敬川、杜衡昌、吕长海、林福生和苏婉宁。仅写归航交船，不提前搬入第 2、3 章的父子相见、未婚妻会面或密告合谋。

译稿完成逐段对照及九项审校；重写完成九项章节自审和人物动机、利益关系、核心冲突、情节结构四项三方差异对照。后端验证章节、段落、来源证据与修订覆盖；文学判断为 Codex 自审，供作者继续复核。
