## 这一版怎样改编

主角林望舟在 1920 年冬被构陷，十四年后逃生，以归侨商人顾砚衡／青屿先生的身份重新进入故人的世界。复仇不靠爵位或无限财力，而通过航运、保证金与限额授信、档案、报馆、商会听证和公开证词展开。

书名中的“长夜”是被夺走的年月，也是归来后被仇恨占据的生活。“归舟”既对应主角姓名，又指向结尾他终于可以启程、而不必靠恨来证明过去真实存在。

- 保留既有姓名，以及职业嫉妒、婚姻嫉妒、毁证自保三种不同责任。
- 傅怀远的财富传承包含执行凭证、核验、旧债清偿及可处分余额，经营与授信有边界。
- 以父母前婚、继母子与出生年份调整解决压缩时间轴后的成年年龄问题。吴照野是吴维岳前婚之子、苏婉宁继子；陈知微、白生和杜觉音均在 1920 年前出生。正式婚恋与约战人物均为成年人。
- 唐知蘅自主保管财产、核验契据并决定如何作证。解契不等于归属新的恩主。
- 陈知微通过知情同意的转移治疗脱险；空棺与死亡误传来自陈家默认，不使用假死神药。顾故意扣留报平安信的过错由她与至诚指出，不写成检验爱情的合理办法。
- 宽恕表现为叫停饥饿私刑、让仇人活着，并继续归还保管款和公开追责。顾的伪造、操纵与欺瞒也留有责任。

1920—1936 年的生活与技术遵循时代边界；澄港、黑礁监、南洋侨港及具体地方机构、案件按架空背景重构。司法、金融与医疗安排是小说设定，不声称复原某一真实案件或具体制度。

## 来源与创作方法

原著为 Project Gutenberg #1184 英文 EPUB，书籍 ID `b2bccd563d774ed184fdafe9fd35b011`，SHA-256 为 `3f22a883c358df0435cfc6b40e69bf27229b36ce6a2285a9151183a0996973f8`。只选择 117 个正文章节，不把目录、卷标、脚注和许可附录算作故事章节。未使用现代中文译本。

当前 Codex 会话通过真实 STDIO MCP 完成项目建立、框架锁定、分析、大纲、正文提交、逐章审查和冻结版本。MCP 提供持久数据与工作流，文学创作由本会话完成。

来源处理通过 MCP 分页取得全部 318 个原文块，使用确定性的段落提取辅助定位，结合章节层面的情节综合形成分析。创作记录中的 `Chapter-level synthesis` 明确指章级综述，`Block extract` 是该块逐字定位依据。它们支持章节合并与因果核对，不是逐句翻译稿。

每个目标章节均记录对应原章和全量来源块；CSV 展开到 117 原章，便于核对范围。36 份审查是 Codex 对自身创作的复核，记录姓名、规则、因果、连续性、创作需求、来源对应及框架适配。
