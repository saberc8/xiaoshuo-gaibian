# 公版原著与改编流程样稿

本目录提供一组可直接导入和阅读的真实素材，用于验证从参考小说到独立改编作品的流程。

另见 [《基督山伯爵》民国改编实测](monte-cristo/README.md)：完整英文 EPUB、前置框架及三章、4,127 字符的《青屿归来》开篇，含四种格式的独立导出。

- `猴爪-English.txt`：W. W. Jacobs《The Monkey’s Paw》的三节英文正文。原文字句未改，统一换行，标题整理为 Chapter I / II / III；去掉下载文件的前后说明与插图占位符，便于选章。
- `pg12122-original-with-license.txt`：完整的原始下载文件，保留来源说明与许可文本。
- `SOURCES.json`：下载来源、处理说明、原始与阅读副本的 SHA-256。
- `adapted/三愿簿-样稿.epub`、`.txt`、`.md`：本次会话创作的三章中文修仙／系统流改编，正文 2,135 字符。
- `adapted/三愿簿-样稿.json`：冻结的来源、需求、原著分析证据、人物与世界观、章节大纲、正文、连续性记忆和 Agent 审查记录。

样稿将二百英镑变为二百灵石，将机器工伤变为宗门炉阵事故，将猴爪变为有三枚愿印的因果簿；保留家庭温情、三愿递进、代价不可撤回和门外留白。它用于演示完整流程，尚未做出版级精修。Agent 的文学检查与后端的证据／覆盖／修订校验在记录中分别可查。

原作来源：[Project Gutenberg #12122](https://www.gutenberg.org/ebooks/12122)。该来源标注为美国公版；具体地区、译本及附加素材的使用依据应分别记录。本次直接从英文原文改编，未使用现代中文译本。

网页中的同名项目保存在本机 `data/`；本目录下的导出文件可独立阅读，不依赖数据库。换到另一台机器时，可导入英文原文并新建自己的改编项目。
